실시간 자막 — 사용법
====================

[처음 한 번]
1. 이 zip 파일의 압축을 풉니다. (마우스 오른쪽 → "압축 풀기" / "모두 압축 풀기")
   ※ zip 안에서 바로 실행하지 말고 꼭 압축을 푼 뒤 실행하세요.

[강의할 때마다]
1. 노트북에 랜선(또는 와이파이)을 연결합니다.
2. 압축을 푼 폴더에서 START.bat 을 더블클릭합니다.
   - "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]
   - "Windows 보안 경고(방화벽)" 창이 뜨면 [액세스 허용]
3. 크롬(또는 엣지)에 송출 화면이 자동으로 열립니다.
4. [세션 만들기] → 화면에 나온 QR 코드를 참석자에게 보여 줍니다.
   (QR을 클릭하면 크게 확대되어 빔프로젝터로 띄우기 좋습니다)
5. 마이크를 고르고 [● 마이크 시작] → 마이크 권한을 [허용]
6. 말하면 자막이 나옵니다.
7. 끝나면 [■ 세션 종료] 후 검은 창을 닫습니다.

[참석자]
- 휴대폰 카메라로 QR을 찍습니다. 앱 설치는 필요 없습니다.
- 노트북이 인터넷(랜선)에 연결되어 있으면 QR은 "인터넷(LTE)" 주소가 되어, 참석자는 와이파이 없이 접속합니다.
- 인터넷이 없으면 QR은 "같은 와이파이" 주소가 됩니다. 참석자가 노트북과 같은 와이파이(또는 노트북 핫스팟,
  최대 8명)에 연결해야 합니다. 송출 화면 "수신 안내"의 목록에서 직접 고를 수도 있습니다.

[알아 두세요]
- 검은 창(서버)을 닫으면 자막이 꺼집니다. 강의 중에는 열어 두세요.
- 음성인식은 노트북 안에서 처리되며, 음성은 외부로 전송되지 않습니다.
- 인터넷(LTE) 접속 시 중계 서버에는 암호화된 자막 텍스트만 지나가며, 서버는 내용을 볼 수 없습니다.
- 마이크는 강사 입에 가까울수록 정확합니다. 강의장 앰프의 녹음 출력(REC/AUX OUT)을
  USB 오디오 어댑터로 노트북에 연결하면 가장 정확합니다.
- 자주 틀리는 단어는 송출 화면의 "용어 사전"에 등록하면 자동으로 고쳐집니다.
